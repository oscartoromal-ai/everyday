- Feature: New project opens a small window to set a project up: its name, its colour, a description and a repository
  On Projects, New project at the header's right takes the place of the name line and Add; Shift+A there opens it too, and so does "New project" in Ctrl+K, on any page.
  Only the name is required: Create project with none says so under it.
  The colour starts on the one fewest open projects have; the description and the repository (one of your GitHub repositories, or a folder or URL as written) are optional.
  Create project opens the new project's page, everything written there already; a repository that cannot be added says why under it, and no project is made.
