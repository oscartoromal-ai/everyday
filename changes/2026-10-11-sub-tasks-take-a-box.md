- Feature: A task's description is plain Markdown: "- " writes a bullet, and "- [ ] " a sub-task
  Every "- " line in a description used to be a sub-task, so a bullet list could not be written.
  Now only a line with a box is a sub-task ("- [ ] ", "- [x] " once done, or Ctrl+L on any line), as in any Markdown, and the sub-tasks already written keep their boxes.
