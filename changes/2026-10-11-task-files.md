- Feature: A task can hold files: Markdown documents beside its description, written on its page or by its agents
  Each task with files has a folder in the everyday files' tasks/, its files the master copy.
  On the task's page they are listed under the task on the map, after its Description: a file opens in the description's place, saved as you write, renamed in its heading and deleted from its bin; New file adds one, a path such as research/trees making its folder.
  An agent launched on the task is told where its files are and to write its plans, research and notes there, and the API and MCP name each task's files.
